# DEEPCORE

DEEPCORE ⛏️

A mining progression game built to run entirely in your browser.

Start with nothing, mine ore, earn money, upgrade your equipment, and build your way toward a massive underground operation.

Features
⛏️ Manual mining
⚙️ Automated mining
💰 Money and ore progression
📈 Upgrade system
💎 Rare ore events
🌙 Offline earnings
💾 Local save system
👤 Local sign-up and login
📱 Desktop and mobile support
🌐 Runs directly in the browser
📄 Single-file game
🎯 Goal

Mine deeper, upgrade your equipment, automate production, and become the ultimate mining operation.

🛠️ Built With
HTML
CSS
JavaScript
Browser LocalStorage
🚀 Play

DEEPCORE is designed to run on GitHub Pages with no server required.
